# Excelerate Companion App

A Flutter mobile app that helps learners discover, apply to and track virtual internship programs, and helps admins manage those programs.

## Project Vision
Make it easy for learners to find the right program, apply in a few taps and follow their progress, while giving admins one place to manage programs and applicants. The app is inspired by Excelerate's learner and admin use cases.

## Objectives
- Let learners browse, search and filter programs.
- Show clear program details (description, weekly plan, deadlines) with an Apply action.
- Give learners a home dashboard with their programs, progress and deadlines.
- Give admins tools to add/edit programs and view applicants.
- Build with clean Flutter structure, version control and reusable widgets.

## Target Users
- **Learner:** browses programs, applies, tracks progress.
- **Admin:** manages programs and applicants.

## Key Features
1. Login / Signup (learner and admin roles)
2. Home dashboard (my programs, progress, deadlines)
3. Program Listing with search and filters
4. Program Details with Apply button
5. Profile (personal info, badges and certificates)
6. Admin: add/edit programs, view applicants (planned)

## Navigation Flow
**Learner:** Login → Home → Program Listing → Program Details → Apply
Bottom navigation: Home | Programs | Profile

**Admin:** Login → Admin Dashboard → Add/Edit Program → Applicants List
