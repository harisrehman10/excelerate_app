# Excelerate Companion App

A Flutter mobile app that helps learners discover, apply to and track virtual internship programs and scholarships, and helps admins manage them.

## Project Vision
Make it easy for learners to find the right program or scholarship, apply in a few taps and follow their progress, while giving admins one place to manage programs and applicants. The app is inspired by Excelerate's learner and admin use cases.

## Objectives
- Let learners browse, search and filter programs and scholarships.
- Show clear program details (description, weekly plan, deadlines) with an Apply action.
- Give learners a home dashboard with their programs, scholarships, progress and deadlines.
- Give admins tools to add/edit programs and scholarships and view applicants.
- Build with clean Flutter structure, version control and reusable widgets.

## Target Users
- **Learner:** browses programs and scholarships, applies, tracks progress.
- **Admin:** manages programs, scholarships and applicants.

## Key Features
1. Login / Signup (learner and admin roles)
2. Home dashboard (my programs, my scholarships, progress, deadlines)
3. Program Listing with search and filters
4. Program Details with Apply button
5. Scholarships: listing, eligibility match, apply
6. Profile (personal info, badges and certificates)
7. Admin: add/edit programs and scholarships, view applicants (planned)

## Planned Extras
- Smart Deadline Tracker for programs and scholarships
- Eligibility Match: scholarships suggested from the learner profile
- Weekly Progress Planner (deliverables checklist)
- Fintech twist: stipend/scholarship and savings goal tracker

## Navigation Flow
**Learner:** Login → Home → Program Listing → Program Details → Apply
Bottom navigation: Home | Programs | Scholarships | Profile

**Admin:** Login → Admin Dashboard → Add/Edit Program or Scholarship → Applicants List
